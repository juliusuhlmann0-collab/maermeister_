# Gesundheit & Zepp-Daten

Kein automatischer Zugriff auf Zepp möglich – es gibt dafür keine Verbindung/API in dieser
Umgebung. Zwei Wege, wie die Daten trotzdem hier landen:

1. **Export aus der App:** Zepp → Profil → Einstellungen → Daten exportieren, Datei schicken,
   ich trage die Werte ein.
2. **Kurz durchgeben:** einfach Schlaf/Schritte/Ruhepuls/Kalorien nennen, wie bei den
   Trainingszahlen – ich trag's unten ein.
